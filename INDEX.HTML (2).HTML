⚠️ El Problema Industrial

Los almacenes de repuestos para vehículos de carga pesada (Minería y Transporte) enfrentan riesgos críticos: colapso de estanterías por sobrepeso y pérdida de trazabilidad de componentes de alto valor como motores y transmisiones.

Este proyecto resuelve la desorganización mediante un modelo relacional que vincula las dimensiones y el peso de cada repuesto con la capacidad física de las zonas de almacenamiento, garantizando seguridad operativa y eficiencia en el despacho.

🗂️ Arquitectura de la Base de Datos

El núcleo del sistema se basa en una estructura de 4 capas relacionales:

EntidadFunción EstratégicaControl de Riesgo
ZonasSegregación por tipo de repuesto (Motores, Neumáticos, Lubricantes).SEGURIDAD
ProductosCatálogo técnico con SKU, peso en Kg y dimensiones en mm.PESO CRÍTICO
UbicacionesMapeo físico por Pasillo y Nivel con ancho disponible.ESPACIO
InventarioControl de stock en tiempo real y cálculo de carga por estante.TRAZABILIDAD

🔎 Consultas de Monitoreo Crítico

El sistema implementa consultas SQL avanzadas para la toma de decisiones:

  • Auditoría de Carga: Cálculo automático del peso total acumulado por ubicación para evitar fatiga de materiales en estanterías.
  • Localización Georeferenciada: Identificación inmediata de repuestos críticos (Urgencias) para flotas detenidas.
  • Análisis de Stock: Reporte consolidado que cruza Zonas, Pasillos y Cantidades.

💻 Stack Tecnológico

Motor de Datos: Microsoft SQL Server 2026.

Capa de Acceso: Entity Framework Core (ORM) para un mapeo de objetos eficiente.

Interfaz: WinForms (C#) con arquitectura desacoplada para reportes dinámicos.

✅ Conclusión del Proyecto

La implementación de LogiStock Pesados demuestra que un diseño de base de datos normalizado es vital para la logística de alto tonelaje. Al integrar variables físicas (peso/volumen) en el modelo relacional, el sistema no solo gestiona inventario, sino que se convierte en una herramienta de prevención de riesgos laborales y optimización de activos para la industria del transporte pesado.
