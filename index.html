⚠️ Problema que Resuelve

Las empresas de transporte de carga ancha necesitan gestionar de forma centralizada el seguimiento de viajes, conductores, vehículos, consumo de combustible, incidencias, mantenimientos y repuestos. Sin un sistema integrado, la información queda dispersa en hojas de cálculo y documentos físicos, generando ineficiencias, pérdida de trazabilidad y mayor riesgo de accidentes.

El sistema propuesto centraliza esta información en una base de datos relacional, exponiendo 10 consultas clave en una interfaz WinForms, permitiendo a los supervisores consultar el estado de flotas, costos operativos e historial de incidencias en tiempo real.

📖 Introducción

El trabajo aplica principios de modelado de base de datos y su integración con Entity Framework (ORM) en el desarrollo de una solución de gestión mediante WinForms. Se demuestra cómo un diseño robusto de tablas y relaciones permite consultas de diversa complejidad, desde CRUD hasta cálculos estadísticos.

🔎 Clasificación de Consultas

Básicas (CRUD)

  • Listar conductores
  • Listar empresas

Intermedias (JOIN)

  • Vehículos con empresa
  • Rutas disponibles
  • Monitoreos detallados
  • Consumo de combustible

Avanzadas (JOIN + lógica)

  • Incidencias con detalle
  • Mantenimientos
  • Proveedores
  • Repuestos con proveedor

💻 Integración Técnica

SQL Server: Creación de la base de datos SeguimientoCargaAnchaDB con tablas y datos de prueba.

ADO.NET: Conexión inicial y ejecución de consultas en WinForms.

Entity Framework: Mapeo de entidades y relaciones con Navigation Properties.

Visual Studio: Interfaz gráfica que permite ejecutar las 10 consultas desde botones y mostrar resultados dinámicos.

✅ Conclusión

El proyecto demostró la importancia de un diseño de base de datos sólido y normalizado como fundamento para aplicaciones de gestión. La implementación de las 10 tablas interrelacionadas garantizó coherencia y escalabilidad, mientras que el uso de Entity Framework facilitó la interacción con la base de datos desde la aplicación en WinForms. Las consultas, desde CRUD hasta reportes avanzados, evidencian la capacidad del modelo para responder a necesidades reales de una empresa de transporte. En conjunto, la integración entre modelado relacional, ADO.NET, ORM y aplicación de escritorio constituye una solución eficiente y adaptable para la gestión y monitoreo de operaciones logísticas.
